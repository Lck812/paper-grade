# 阅卷台

面向老师和助教的电子答卷批改网页。把标准答案和学生作答整理成 CSV，网页会批改客观题，显示逐题得分，再导出可在电子表格软件中打开的成绩表。

## 试用

在项目根目录运行 `python -m http.server 8765 --bind 127.0.0.1 --directory dist`，用浏览器打开 [本地阅卷台](http://127.0.0.1:8765/)。点击「载入示例」和「开始批改」，可体验三份虚构答卷。

生产部署时，将 `dist/` 整个目录交给静态网站托管服务。运行网页无需安装 JavaScript 依赖。

## 批改自己的答卷

1. 下载两份模板，或直接把 CSV 文本粘贴到网页。答案表表头为 `题号,题型,答案,分值`。答卷表首列为 `姓名`，其他列使用对应题号。
2. 答案表支持单选、多选、判断、填空和主观。多选全对才得分，选项顺序不限。判断使用答案表给出的写法，例如「对」或「错」。填空用竖线 `|` 分隔可接受的答案。主观题的答案列可填评分参考或留空。分值最多两位小数。
3. 开始批改后，在结果中为主观题录分。待复核的总分为暂计分，导出的成绩表也会标出状态。编辑导入表格会清除当前批改结果，请先导出需要保留的成绩。

CSV 文件建议保存为 UTF-8。导入同时尝试 GB18030。答卷只保留在当前页面内存中，刷新或关闭页面会清空数据。当前支持已录入为 CSV 的作答，拍照、扫描 PDF 和识别手写答案不在本版范围内。

## 测试

使用 Node.js 22 或更新版本运行 `node --test`。
