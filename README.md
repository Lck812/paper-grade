# 阅卷台

面向老师和助教的电子答卷批改工具。老师登录后可以在线收卷，也可以导入班级表格或单份答卷。网页自动批改单选、多选、判断和填空题，老师可以复核主观题并导出逐题成绩。

## 在线阅卷

[打开阅卷台并登录](https://paper-grade-workbench.heapedgrebe8.chatgpt.site/)

1. 用自己的 ChatGPT 账号登录阅卷台，上传标准答案并核对题型、答案和分值。
2. 若要在线收卷，输入试卷名称，点击「用标准答案创建收卷」，再将学生链接分享给学生。学生用自己的 ChatGPT 账号登录，填写姓名和各题答案。
3. 重新登录会自动载入当前收卷，点击「刷新答卷」可查看最新提交。需要加入编辑区时点击「载入在线答卷」，再上传需要补录的答卷。
4. 点击「开始批改」，填写主观题得分并导出成绩 CSV。

每个老师账号可创建一份当前收卷，最多 120 道题、300 份在线答卷。学生页面只显示题号，老师可同时提供题面。学生重新提交会替换该账号的上次作答。删除收卷会删除其中的在线答卷，并使学生链接失效。

## 文件格式

- **标准答案 CSV** 的表头为 `题号,题型,答案,分值`。题型为单选、多选、判断、填空或主观。填空可用 `|` 分隔多个可接受答案。
- **标准答案 TXT 或 PDF** 可写成每题一行，例如 `1. A（2分）`。系统会推断题型，未注明的分值暂设为 1。长文本会暂设为填空题，需要人工评分时请把题型改为「主观」。
- **班级答卷 CSV** 的首列为 `姓名`，其余列为题号，每位学生一行。单份 **TXT 或 PDF** 可用 `姓名：学生甲` 开头，后续每题一行，例如 `1. A`。没有姓名行时使用文件名。
- PDF 需要可选中的文字层，每份最多 30 页、12 MB。扫描件需先做 OCR。复杂排版可以先整理成逐题文本或 CSV。

导入的原始文件在浏览器内读取。在线收卷保存试卷名称、标准答案、学生姓名、提交时间和作答内容，仅创建收卷的老师账号可以读取完整数据。手动补录的答卷、复核分数和成绩留在当前页面，关闭前请导出。

## 本地运行和测试

使用 Node.js 22 或更新版本。执行 `npm ci` 后，运行 `npm test`。执行 `npm run build:static` 并用静态 Web 服务器托管 `dist/`，可在本地测试文件导入和判分。

`npm run build` 生成 Sites Worker，部署需要 Sites 的请求身份和名为 `DB` 的 D1 绑定。初始化数据库使用 `drizzle/0000_collections.sql`。静态托管可运行文件导入和判分。账号登录与在线收卷由 Sites Worker 提供。

PDF 文字提取使用 [Mozilla PDF.js](https://mozilla.github.io/pdf.js/)，构建时复制依赖及其许可证至静态目录。
